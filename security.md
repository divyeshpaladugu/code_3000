# Security

## Intended Users
The intended users of this repository are the course instructor, TAs, and the student who created the repository. The code is only meant to be used for completing and submitting class assignments.

## Security Risks
The main risk is that someone could copy the code and use it as their own work, which could violate academic integrity rules. There are no passwords, API keys, or sensitive personal data stored in this repository, so the overall security risk is low.

## Steps Taken to Secure the Repository
No special security measures are necessary because the repository only contains assignment code and does not include sensitive information. Care is taken not to store passwords, private keys, or other secrets in the repository.
